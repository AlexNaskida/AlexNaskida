## Current system

### DeDNS-over-DeVPN

**Anonymous, session-based internet access with enforceable and revocable relay permissions.**

The project combines:

- ENSv2-based identity and naming
- Chainlink CRE for verifiable off-chain coordination
- Arc and x402-based settlement flows
- permissioned relay infrastructure
- session-level access control
- cryptographic authorization instead of platform tenancy

The objective is not to add a token to networking.

It is to examine whether access, identity, settlement, and revocation can be expressed as protocol primitives rather than informal platform permissions.

## Research position

The model is not the event.

The event is substrate plus continuation:

- compute requires energy
- protocols require settlement
- identities require keys
- infrastructure creates chokepoints
- law determines who may freeze or revoke access

AI, crypto, finance, and network infrastructure should therefore be read as one connected system without collapsing them into the same thing.

Crypto does not need to defeat intelligence.

It needs to remain a way of organizing ownership, authorization, and settlement that is not merely a tenancy inside someone else’s platform.
